Row-level security

One model, one report, but each person sees only the rows they are allowed to see.

1. Create and test roles

  1. Power BI Desktop → Modeling → Manage roles → Create. Name the role.
  2. Select a table and write a DAX filter that returns TRUE or FALSE for each row.
  3. Modeling → View as: pick the role (and optionally another user) to test the report as that person.
  4. Publish. In the Power BI service: semantic model → Security → add users or groups to each role (then test with “Test as role”).
// static: a role for one region
[Region] = "East"

// dynamic: one role for everybody; rows are matched to the signed-in user
[ManagerEmail] = USERPRINCIPALNAME ()

2. Static vs dynamic

Static RLSDynamic RLS
FilterHard-coded valueUses USERPRINCIPALNAME() (or USERNAME()) and a mapping column / security table
Roles neededOne per group of rowsOne role for everyone
MaintenanceEdit roles for every changeUpdate the data in the security table

3. How filters behave

  • A filter on a dimension table flows to related fact tables through the one-to-many relationship (filter direction). To filter the other way enable Apply security filter in both directions on the relationship.
  • If a user is in several roles, they see the union of the rows allowed by those roles.
  • RLS works with Import and DirectQuery, and also applies to Analyze in Excel, apps and embedded reports.
  • RLS applies to workspace Viewers and to users who get content via an app or a share link. It does not apply to Admins, Members and Contributors.
  • Object-level security (OLS) hides tables or columns from a role; it is configured with an external tool such as Tabular Editor.
Exam trapAdding a user in Desktop’s Manage roles dialog does nothing: members are assigned in the service. And testing as a workspace Admin always shows all rows.
Key takeaways
  • Manage roles + DAX filter, test with View as, assign members in the service.
  • Dynamic RLS = USERPRINCIPALNAME() + a security table.
  • Multiple roles = union; RLS affects Viewers, not Admin / Member / Contributor.
