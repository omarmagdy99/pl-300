Drillthrough, tooltips & bookmarks

Turn a set of charts into a guided story with navigation, detail pages and toggles.

1. Hierarchies and drill

  • Create a hierarchy in the Data pane by dragging one field onto another (Category → Subcategory → Product). Dates have a built-in Year → Quarter → Month → Day hierarchy.
  • Visual header buttons: Drill down, Drill up, Go to the next level (shows all values one level down), Expand all.

2. Drillthrough

A drillthrough page shows detail for one item (a customer, a product) picked on another page.

  • Create a page and add the field (for example Customer) to the Drill through well.
  • Users right-click a data point (in any visual that has that field) → Drill through → the page.
  • Power BI adds a Back button automatically. Keep all filters carries the other filters along. Drillthrough can also target another report (cross-report).

3. Report page tooltips

Create a small page, turn on Page information → Allow use as tooltip (tooltip page size), design a mini chart. On a visual, set Format → General → Tooltips → Type: Report page and pick that page: hovering shows the chart.

4. Bookmarks, buttons and the Selection pane

  • Bookmark = a saved state: filters and slicers (Data), visibility of visuals (Display), page (Current page); options apply to all visuals or selected ones.
  • View → Bookmarks pane. After changing a bookmark’s view, choose Update.
  • Use the Selection pane to show / hide visuals and give them clear names.
  • Buttons: Back, Bookmark, Page navigation, Q&A, Web URL. Assign the Action (type: Bookmark / Page navigation / Drillthrough…).
  • Chart ↔ table toggle: make two bookmarks (one hides the table, one hides the chart) and attach each to a button.
  • The page navigator and bookmark navigator visuals create menus automatically.

5. Field parameters

Modeling → New parameter → Fields creates a table and slicer that lets users switch the measures or fields shown in a visual (for example Sales, Profit or Quantity on the same chart).

Exam trap“Jump to a detail page for the clicked customer” → drillthrough (not a bookmark). “Toggle between two visuals on the same page” → bookmarks + buttons + Selection pane. “Hover shows a chart” → report page tooltip.
Key takeaways
  • Drillthrough = detail page + field in the Drill through well; Back button is automatic.
  • Bookmarks store data, display and page state; buttons trigger them.
  • Field parameters let users choose the measure or field in a visual.
