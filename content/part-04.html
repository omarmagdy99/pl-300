Shape & transform tables

Reshape wide tables, aggregate rows, split and create columns.

1. Pivot, unpivot, transpose

CommandDoesTypical case
Unpivot ColumnsTurns the selected columns into Attribute / Value rowsFixed set of columns
Unpivot Other ColumnsUnpivots everything except the selected columnsNew columns (months) will appear later
Unpivot Only Selected ColumnsSame as Unpivot Columns (keeps only those selected)—
Pivot ColumnTurns the values of a column into new column headers; needs a Values column and an aggregationRows → columns
TransposeSwaps rows and columns (headers are lost)Rotated tables
// Product | Jan | Feb | Mar   →   Product | Month | Sales
Table.UnpivotOtherColumns(Source, {"Product"}, "Month", "Sales")

2. Group By

Transform → Group By. Aggregations: Sum, Average, Min, Max, Median, Count Rows, Count Distinct Rows, All Rows (nested table). Use Advanced to group by several columns or add several aggregations.

3. Split & merge columns

  • Split Column — by delimiter, number of characters, positions, lowercase→uppercase, digit→non-digit. Output into columns or into rows.
  • Merge Columns — combine columns with a separator (opposite of split).
  • Extract — Text Before / After / Between Delimiters, First/Last Characters, Length.

4. Add Column tab

CommandUse

Conditional ColumnIf / else-if / else rules without code
Index ColumnSequential numbers from 0, 1 or custom (breaks query folding)
Duplicate ColumnCopy of an existing column
Exam trapIf new columns can appear in the future, choose Unpivot Other Columns. Selecting the old month columns and choosing Unpivot Columns would miss the new ones.
Key takeaways
  • Wide → tall = Unpivot. Tall → wide = Pivot.
  • Conditional Column for rules; Column From Examples for patterns.
  • Group By → “All Rows” gives you a nested table.
