Clean the data

Fix types, nulls, errors, spaces, duplicates and header rows.

1. Data types

  • Set types on the column header icon or Transform → Data Type. Always set types explicitly.
  • Using Locale… converts text that follows another culture’s format (for example 31/03/2024 as English (United Kingdom)).
  • Auto detection: File → Options → Data Load → Type Detection.

2. Nulls and errors

CommandEffect
Replace ValuesSwap a value for another (type null to make a real null)
Replace ErrorsKeeps the row; error cells get a new value
Remove ErrorsDeletes the rows that contain errors
Remove Empty / Remove Blank RowsDeletes empty rows
Fill Down / Fill UpCopies the nearest non-null value into the null cells below / above (typical for grouped Excel reports)
// "N/A" → null first, THEN change the type
let
    Source = Excel.Workbook(File.Contents("C:\Sales.xlsx"), null, true),
    Replaced = Table.ReplaceValue(Source, "N/A", null, Replacer.ReplaceValue, {"Sales"}),
    Typed = Table.TransformColumnTypes(Replaced, {{"Sales", type number}}),
    Filled = Table.FillDown(Typed, {"Region"})
in
    Filled

3. Text clean-up

  • Trim — removes leading and trailing spaces.
  • Clean — removes non-printable characters.
  • Format: lowercase, UPPERCASE, Capitalize Each Word.

4. Duplicates and rows

  • Remove Duplicates is case-sensitive. “Cairo” and “cairo” are different — lowercase first if needed.
  • Keep / Remove Rows: Top, Bottom, Alternate, Range, Duplicates, Errors.
  • Use First Row as Headers / Use Headers as First Row.
Exam trapRemove Errors loses rows; Replace Errors keeps them. Replacing text such as “N/A” before converting the type avoids creating errors in the first place.
Key takeaways
  • Order matters: clean values → then change type.
  • Fill Down for grouped data, Trim vs Clean, Using Locale for foreign dates.
  • Remove Duplicates is case-sensitive.
