Filters, slicers & interactions

Let users narrow the data, and control how visuals react to each other.

1. The Filters pane

ScopeApplies to
Visual levelThe selected visual only
Page levelAll visuals on the current page
Report level (“All pages”)Every page in the report
DrillthroughOnly on a drillthrough page (the passed-in value)
Filter typeExample
BasicTick the categories to keep
Advanced“contains” / “is greater than”, with And / Or
Top NTop 5 products by Total Sales (visual level filter on a category)
Relative date / timeLast 30 days, this month, next 2 weeks

As a report author you can lock or hide a filter so readers can’t change it.

2. Slicers

  • Styles: list, dropdown, tile/buttons, between (numeric / date range), relative date, hierarchy.
  • Selection: multi-select by default; turn on Single select to allow one value; optional Select all, search box.
  • Sync slicers (View → Sync slicers): choose which pages the slicer syncs to (Sync column) and on which pages it is shown (Visible column).
  • Add an Apply button to slicers to reduce queries on big models.

3. Visual interactions

Selecting an element in one visual cross-filters or cross-highlights the others. Use Format → Edit interactions, select the source visual and pick for each target: Filter, Highlight or None.

  • Ctrl-click selects several elements.
  • Setting a slicer’s interaction to None for one visual stops that visual from reacting to it.
  • Slicers and filters can be applied in Reading view; users can reset them to the saved state.
Exam trapA slicer is limited to its page unless it is synced to other pages. Page-level filters affect only that page; use report-level filters for every page. To exclude one chart from a slicer, use Edit interactions → None, not a visual filter.
Key takeaways
  • Visual, page and report filter scopes; Basic, Advanced, Top N and Relative date types.
  • Sync slicers = Sync + Visible columns.
  • Edit interactions: Filter / Highlight / None.
