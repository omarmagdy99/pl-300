Get or connect to data

Choose the right connector, the right storage mode, and manage how Power BI authenticates to the source.

On-premises sources (a local SQL Server, a file share) need an on-premises data gateway for scheduled refresh in the Power BI service.

2. Storage modes — the most tested topic of this part

ModeWhere is the data?Use it whenLimits
ImportCompressed copy in the model (VertiPaq, in memory)Best performance; full DAX and Power Query supportNeeds refresh; model size limits apply (for example 1 GB compressed on Pro)
DirectQueryStays in the source; queries are sent on every interactionVery large data, or near real-time dataSlower visuals; only transformations that translate to a native query; 1 million row limit on a query result
DualBoth — acts as Import or DirectQuery depending on the queryDimension tables in a composite model (related to a DirectQuery fact table)Needs a composite model
Live connectionA published Power BI semantic model (or Analysis Services)Reuse one governed model across many reportsYou can't change its tables; you can add report-level measures

A model that mixes Import and DirectQuery tables is a composite model. In Microsoft Fabric, Direct Lake reads Delta tables from OneLake directly, with Import-like speed and no import copy.

3. Data source settings

  • Open: Home → Transform data → Data source settings. Here you edit permissions (credentials) and Change Source.
  • Authentication kinds: Windows, Database, Basic, Organizational account (OAuth), Anonymous.
  • Privacy levels: Private, Organizational, Public. They stop data from one source being sent to another source during a combine/folding operation. Conflicts cause the Formula.Firewall error.

4. Combine files from a folder

Use the Folder connector → Combine & Transform Data. Power Query creates a Sample file, a parameter, a function and a combined query — new files in the folder are picked up on the next refresh without editing the query.

Exam trap“Near real-time + huge table + no scheduled refresh” → DirectQuery. “Fastest visuals + data fits in memory” → Import. A dimension table that joins both worlds → Dual.
Key takeaways
  • Know the 4 modes: Import, DirectQuery, Dual, Live connection.
  • Folder + Combine = automatic loading of new files.
  • Privacy-level conflicts → Formula.Firewall.
