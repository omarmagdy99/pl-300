Choose & format the right visual

Start from the question your audience is asking, then pick the visual that answers it clearly.

1. Match the visual to the question

You want to show…Use
Compare categoriesBar / column (clustered), sorted
Trend over timeLine or area chart
Part of a whole (few categories)Pie / donut, stacked bar, treemap (many)
Relationship between two measuresScatter / bubble chart
Increase and decrease contributionsWaterfall
Stages that shrinkFunnel
Rank changes over timeRibbon chart
Two measures with different scalesLine and clustered column (combo, secondary axis)
GeographyMap, filled map, shape map
One key number / statusCard, KPI, gauge
Exact values and detail rowsTable (rows) or matrix (rows + columns, subtotals)
  • Pie and donut: only a few slices. Many similar categories → bar chart.
  • Sort bars by value; start bar axes at zero; limit colors; one message per visual.
  • Small multiples split one visual into panels by a category (line, column, bar, area).

2. Field wells

Axis (categories), Legend (series split), Values (measures), Small multiples, Tooltips (extra fields shown on hover without changing the visual), Details (granularity).

3. Formatting and conditional formatting

  • Format pane → Visual tab (data labels, axes, colors, title) and General tab (size, title, background, border, alt text).
  • Conditional formatting (the fx button): background color, font color, data bars, icons, web URL.
Format styleUse it when
GradientColor scale from a minimum to a maximum value
RulesFixed thresholds (e.g. red if < 0, green if ≥ 0)
Field valueA column or measure returns the color (hex such as #D64550)
  • Sorting: sort a visual from its “…” menu; to change a text column’s order permanently use Sort by column in the model.
  • Themes: View → Themes for consistent colors and fonts across the report.
Exam trapRelationship between two numeric measures → scatter, not line. Variance / bridge between a start and end value → waterfall. Rows and columns with subtotals → matrix, not table.
Key takeaways
  • Pick the visual from the question: compare, trend, part-to-whole, relationship, flow.
  • Conditional formatting: Gradient (scale), Rules (thresholds), Field value (color from a measure).
  • Tooltips well and small multiples add detail without clutter.
