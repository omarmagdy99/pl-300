Layout, themes, accessibility & mobile

A report is only useful if people can read it, on any device and with any ability.

1. Layout and canvas

  • Format → Align / Distribute to line visuals up and space them evenly; Group visuals that belong together.
  • Selection pane: name visuals, hide them, change layer (z-order).
  • Canvas settings (Format pane → Page): size (16:9 default, 4:3, Letter, tooltip, custom), background, wallpaper. View → Page view (fit to page / width).
  • Gridlines and snap to grid help alignment. Leave white space; put the most important visual top-left.

2. Themes

  • View → Themes: built-in themes, Customize current theme, or Browse for themes to import a JSON file with your brand colors and fonts.
  • A theme sets default data colors, text, backgrounds and visual styles for every visual.
  • A template (.pbit) saves layout and model for reuse.

3. Accessibility

PracticeHow
Alt textFormat → General → Alt text on each meaningful visual (read by screen readers)
Tab order / keyboardSet the tab order in the Selection pane so keyboard users move in a logical sequence; hide purely decorative items
Titles and labelsClear titles; data labels where needed
ColorGood contrast; color-blind-friendly palette; never use color alone (add labels, icons, patterns)
Show as tableLets users see the data behind a visual
High contrast modePower BI follows Windows high contrast themes

4. Mobile layout

View → Mobile layout opens a phone canvas. Drag the visuals you want onto it and arrange them for a portrait screen; nothing is added automatically and the desktop layout stays unchanged. Phone users see this layout in the Power BI mobile app.

  • Also consider Personalize visuals so readers can change a visual type or fields themselves, and bookmarks for default views.
Exam trapBrand colors for the whole report → import a theme JSON (don’t recolor visuals one by one). Phone optimization → Mobile layout (not a 4:3 page size). Screen-reader description → alt text.
Key takeaways
  • Align/Distribute, Selection pane, canvas size for layout.
  • Themes: View → Themes → JSON. Template = .pbit.
  • Accessibility: alt text, tab order, contrast, not color alone. Mobile layout is built manually.
