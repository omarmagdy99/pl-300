Analytics & AI visuals

Go beyond “what happened”: find patterns, outliers, drivers and forecasts.

1. The Analytics pane (magnifier icon)

Available on cartesian visuals such as line, bar, column, area and scatter charts.

FeatureUse
Constant / Min / Max / Average / Median / Percentile lineReference lines such as a target or an average
Trend lineDirection of the data (linear regression)
ForecastPredicts future values on a line chart with a date/time axis; set length, confidence interval and seasonality
Error barsUpper and lower bounds
Find anomaliesMarks unexpected spikes or dips on a line chart and suggests explanations
Symmetry shadingScatter chart: highlight which axis is bigger

2. AI visuals

VisualAnswers
Key influencers“What drives this metric?” Analyze a metric (a category such as Churn = Yes, or a number); Explain by fields; also shows top segments
Decomposition tree“Where does this number come from?” Split a measure by dimensions in any order; AI splits pick the highest / lowest contributor
Q&AType a question in natural language and get a visual
Smart narrativeAuto-generated text summary of a visual or a page
Explain the increase / decreaseRight-click a point on a column / line chart to get possible reasons

3. Grouping, binning and clustering

  • Group: right-click a field → New group to combine values into your own categories.
  • Bin: on a numeric or date field choose New group and set a bin size (for example age ranges of 10 years) to build a histogram.
  • Clustering: on a scatter chart, Automatically find clusters.
  • Outliers are visible in scatter charts and with anomaly detection or Top N / Bottom N.

4. Reading patterns

  • Trend = long-term direction, seasonality = repeating pattern, outlier = unusual point.
  • Correlation is not causation: a key influencer is an association.
Exam trapForecast needs a line chart with a date axis. Key influencers = “what influences a metric”; decomposition tree = “break a total down and drill into contributors”. Q&A is for asking in plain language.
Key takeaways
  • Analytics pane: lines, trend, forecast, error bars, anomalies.
  • Key influencers (drivers), decomposition tree (root cause), Q&A, smart narrative.
  • Bins: New group with a bin size.
