CALCULATE, filters & statistics

CALCULATE is the most important function in DAX: it changes the filter context.

1. CALCULATE

CALCULATE ( <expression>, <filter1>, <filter2>, … ) evaluates the expression after applying the filters. A filter on a column replaces any existing filter on that same column.

Red Sales = CALCULATE ( [Total Sales], Product[Color] = "Red" )

All Sales = CALCULATE ( [Total Sales], ALL ( Product ) )

% of Total = DIVIDE ( [Total Sales], CALCULATE ( [Total Sales], ALL ( Product ) ) )

% of Category =
DIVIDE ( [Total Sales], CALCULATE ( [Total Sales], ALLEXCEPT ( Product, Product[Category] ) ) )

Big Orders = CALCULATE ( [Total Sales], FILTER ( Sales, Sales[Amount] > 1000 ) )

2. Filter functions

FunctionWhat it does
ALLRemoves all filters from a table / columns (returns all rows)
ALLEXCEPTRemoves all filters from a table except the listed columns
ALLSELECTEDRemoves the filters of the current visual but keeps the outer ones (slicers, filters). Use for “% of the visible total”
REMOVEFILTERSClears filters; works only as a CALCULATE modifier (clearer name than ALL)
VALUES / DISTINCTThe distinct values currently visible in a column
SELECTEDVALUEThe value if exactly one is selected, otherwise blank (or an alternate result)
HASONEVALUE / ISFILTEREDTests about the current filter context
FILTERReturns a table of the rows that meet a condition; it iterates (can be slow on big tables)

Context transition: CALCULATE turns the current row context into an equivalent filter context. That is why referencing a measure inside a calculated column or an iterator works: Power BI wraps it in an implicit CALCULATE.

3. Semi-additive measures

Balances and inventory levels must not be summed across time. Take the value at the last date instead:

Closing Balance =
CALCULATE ( SUM ( Balances[Amount] ), LASTDATE ( 'Date'[Date] ) )

// or: CLOSINGBALANCEMONTH / CLOSINGBALANCEQUARTER / CLOSINGBALANCEYEAR

4. Basic statistical functions

  • AVERAGE, MEDIAN, MIN, MAX, STDEV.P / STDEV.S, PERCENTILE.INC; iterator versions AVERAGEX, MEDIANX…
  • RANKX ( ALL ( Product[Name] ), [Total Sales] ) ranks each product.
  • TOPN ( 10, Customer, [Total Sales] ) returns the top 10 rows of a table.
  • VAR … RETURN stores intermediate results: easier to read and calculated once.
Exam trapALL ( Product ) clears everything on Product, including a Category slicer. To keep the slicer selection use ALLSELECTED ( Product ). Prefer a Boolean filter (Product[Color] = "Red") to FILTER ( Product, … ): it is faster.
Key takeaways
  • CALCULATE = expression + new filters (replace filters on the same column).
  • ALL clears, ALLEXCEPT keeps some, ALLSELECTED keeps the outer slicers.
  • Balances: LASTDATE / CLOSINGBALANCE…, never a plain sum over time.
