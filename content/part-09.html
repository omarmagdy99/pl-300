Date tables & time intelligence

Year-to-date, last year, rolling 3 months: all of them need a proper date table.

1. What a good date table looks like

  • One row per day, contiguous (no missing dates) and covering full years.
  • A column of Date data type with unique values.
  • Related to the fact table’s date column (one-to-many, single direction).
  • Marked as date table (Table tools → Mark as date table) and the date column chosen.
  • Extra columns: Year, Quarter, Month number, Month name (sorted by Month number), Week, Fiscal year…

2. Creating one

// DAX calculated table
Date = CALENDAR ( DATE ( 2020, 1, 1 ), DATE ( 2026, 12, 31 ) )

// or let DAX scan every date column in the model and return whole years
Date = CALENDARAUTO ()

Year        = YEAR ( 'Date'[Date] )
MonthNumber = MONTH ( 'Date'[Date] )
Month       = FORMAT ( 'Date'[Date], "MMMM" )   // sort by MonthNumber
Quarter     = "Q" & QUARTER ( 'Date'[Date] )

You can also build the date table in Power Query or load it from your data warehouse. Auto date/time (File → Options → Data Load → Time intelligence) creates a hidden date table for every date column. Turn it off when you use your own date table to save memory.

3. Time intelligence functions

FunctionReturns
TOTALYTD / TOTALQTD / TOTALMTDRunning total for the year / quarter / month so far (a value)
DATESYTD / DATESQTD / DATESMTDThe dates of the period so far (a table, used inside CALCULATE)
SAMEPERIODLASTYEARThe same dates one year earlier
DATEADD(dates, n, interval)Shifts dates by n days / months / quarters / years
DATESINPERIODA window ending at a date, e.g. the last 3 months
DATESBETWEENDates between a start and an end
PREVIOUSMONTH / PARALLELPERIODThe previous month / a parallel period
Sales YTD = TOTALYTD ( [Total Sales], 'Date'[Date] )

Sales YTD (FY ends 30 June) =
TOTALYTD ( [Total Sales], 'Date'[Date], "6/30" )

Sales LY = CALCULATE ( [Total Sales], SAMEPERIODLASTYEAR ( 'Date'[Date] ) )

YoY % = DIVIDE ( [Total Sales] - [Sales LY], [Sales LY] )

Rolling 3M =
CALCULATE (
    [Total Sales],
    DATESINPERIOD ( 'Date'[Date], MAX ( 'Date'[Date] ), -3, MONTH )
)
Exam trapAlways pass the date column of the date table, not the fact table’s date column, to time intelligence functions. Wrong or blank results usually mean gaps in the dates or a missing relationship.
Key takeaways
  • Contiguous dates, full years, unique Date column, related and marked as date table.
  • CALENDAR needs start and end; CALENDARAUTO finds them for you.
  • Fiscal year: third argument of TOTALYTD, for example "6/30".
